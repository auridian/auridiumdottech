Make state legislative information usable.

Granite Docket brings fragmented New Hampshire legislative information into one searchable, navigable system for bills, legislators, hearings, calendars, and related public activity.

Status

Live

Audience

New Hampshire residents and civic researchers

Product

Visit Granite Docket

Problem

State legislative information is distributed across public sources, uses inconsistent identifiers and formats, and can be time-consuming to search and monitor. The public needs a practical way to move between representatives, bills, meetings, and dates without learning the shape of every source system.

Constraints

  • Multiple public sources with different structures
  • Changing calendars, meetings, and hearing information
  • Reliable search and cross-linking across related records
  • A responsive public interface with limited maintenance overhead
  • Clear separation from official state sources

System

The live product provides representative lookup, bill search and detail views, legislator and committee information, calendars, votes, and elections. Navigation and cross-links let a visitor move through the civic record using recognizable public concepts rather than source-system identifiers.

Result

Granite Docket consolidates several public information views into one interface, reduces the number of source sites a visitor must navigate, and provides a reusable model for connecting legislative records. It is a public civic tool, not an official government source.

Technologies

Web application, structured public data, search, data normalization, and responsive interface design.
